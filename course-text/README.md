# AI Programming — Cursus

Deze cursus is gebaseerd op de slides van AI Programming (Bruno Herman, AP Hogeschool) en de bijhorende oefeningen. De bedoeling is om de slides iets uitgebreider uit te leggen, met compacte Python syntaxvoorbeelden.

## Hoofdstukken

| # | Hoofdstuk | Onderwerpen |
|---|-----------|-------------|
| 01 | [Intelligente Agents](01_intelligente_agents.md) | AI vs ML, agent framework, PEAS, agent types, AI geschiedenis |
| 02 | [Sorteeralgoritmes](02_sorteeralgoritmes.md) | Big O, bubble sort, merge sort, vergelijking |
| 03 | [Zoekalgoritmes](03_zoekalgoritmes.md) | BFS, DFS, geïnformeerd vs ongeïnformeerd, schuifpuzzel |
| 04 | [Lokale Zoekalgoritmes](04_lokale_zoekalgoritmes.md) | Gradient descent, simulated annealing, optimalisatie |
| 05 | [Adversarial Search](05_adversarial_search.md) | Minimax, game trees, depth-limited search |
| 06 | [Alpha-Beta & Expectimax](06_alpha_beta_expectimax.md) | Alpha-beta pruning, expectimax, stochastische spellen |
| 07 | [Stochastische Problemen](07_stochastische_problemen.md) | AND-OR trees, belief-state space |
| 08 | [Lineair Programmeren](08_lineair_programmeren.md) | OSQP, matrices, constraints, data fusion |
| 09 | [Reinforcement Learning](09_reinforcement_learning.md) | Explore vs exploit, epsilon-greedy, Gittins index |
| 10 | [Q-Learning](10_qlearning.md) | Q-tabel, Q-update, discretisatie, taxi-voorbeeld |
| 11 | [Genetische Algoritmes](11_genetische_algoritmes.md) | OneMax, crossover, mutatie, TSP, knapsack |
| 12 | [Agentic Programming](12_agentic_programming.md) | Tool agents, self-improving, LLM agents, evolutionaire agents |
